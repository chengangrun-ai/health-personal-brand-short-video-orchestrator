# content-repurposing — 内容裂变与多平台改编（裂变层）

## 定位与分工

| 层 | Skill | 负责 |
|---|---|---|
| 人格层 | `brand-voice` | **像不像我**、AI 味终审 |
| 内容层 | `content-and-copy` | 具体文字文案（文章/公众号/小红书/标题/金句） |
| 写法层 | `short-form-video-script` | 短视频脚本 / 口播稿 |
| 裂变层 | `content-repurposing`（本 Skill） | **母体 → 哪些值得裂变 → 怎么切 → 分给谁做**，不直接写完所有衍生稿 |

本 Skill 是「分发前的改编」：把一份母体切成多个**适配不同载体的独立作品**，不是把同一段文字贴遍所有平台。

原始哲学（保留）：**Adaptation is craft, not duplication.** 每个衍生内容都要当成独立的作品，尊重它所在载体的习惯，用我的声音写、按载体的工艺做。

---

## 铁律

1. **质量优先，不凑数量。** 「1 条 = 10 条」是错误目标。一个母体如果只够出 3 个高质量衍生，就只出 3 个。
2. **不机械化改写。** 禁止「同一个观点换 10 种说法」。优先找真正不同的：角度 / 人群 / 场景 / 冲突 / 故事 / 观点 / 平台表达方式。
3. **不改母体事实。** 裂变只能重组、裁剪、换载体，不能改原始观点、原始数据、原始经历。
4. **不编造平台规则。** 平台算法、标签机制、当前流量规则会变；只给稳定已知的载体习惯（长度、开头、互动方式），并标注「以你实际测到的为准」。不确定的不编。
5. **终审交 brand-voice。** 所有衍生内容必须过 AI 味检测，不通过自动重写。不得为适配平台牺牲真实感、变成标准营销号。

## 内容母体（Content Source）

输入任一类：一条短视频 / 一份脚本 / 一篇文章 / 一段长文 / 一次采访 / 录音转文字 / 直播 / 观点 / 故事 / 案例。

**先提取 8 项：**
`核心观点` / `核心故事` / `核心信息` / `金句` / `案例` / `情绪` / `冲突` / `可传播片段`

**再判断哪些值得裂变**（原 Skill 的 source-piece selection）：母体要有能独立成立的子论点、子故事、子案例，才值得拆。一个环环相扣、必须从头读到尾的叙事，强行拆会碎 —— 这种留给「一条主视频 + 一条幕后」就够。

把母体登记到内容矩阵（`~/.workbuddy/content-assets/content-map.md`）。

---

## 裂变（质量上限决定数量）

以一条 60 秒视频为例，可产出（**按需、不强制、不凑**）：
- 3 个不同 Hook 版本（各一帧 Hook 测试用，非成片）
- 30s / 60s / 90s 版本（同一内容不同容量）
- 小红书笔记
- 朋友圈版本
- 视频号文字说明
- 评论区互动话术
- 第二条延伸视频选题
- 第三条反向观点视频选题

**每个衍生都过「litmus test」：** 假设观众只看到这一个衍生、没看过母体，它能不能独立成立？用没用所在载体的习惯？会不会被当成「该去看原文」？三项都「是」才算合格。

## 平台适配

重点考虑：抖音 / 视频号 / 小红书 / 朋友圈。不同平台不能只换几个词。

| 平台 | 长度 | 标题/开头 | 信息密度 | 互动 | CTA | 语言习惯 |
|---|---|---|---|---|---|---|
| 抖音 | 短（15–90s 为主） | 前 1–3 秒强 Hook | 高，一秒一个信息点 | 评论/合拍 | 轻，点赞关注 | 口语、冲、直接 |
| 视频号 | 可稍长，私域转发 | 开头可慢半拍（熟人场景） | 中 | 转发/点赞 | 引导转发/关注 | 稳、可信、不让熟人尴尬 |
| 小红书 | 图文或短视频 | 首句即钩子，标题党但要真实 | 中，留白多 | 收藏/评论 | 弱，引导收藏 | 第一人称、换行多、emoji 节制 |
| 朋友圈 | 极短 | 不写标题，直接说人话 | 低，一条一个意思 | 点赞/私信 | 无 | 私人、随意、绝不像营销号 |

**不确定某个平台的当前具体规则（如标签机制、推流逻辑）→ 不编造，标注「以你实测为准」。**

## 协同管道（不重复造轮子）

**文字衍生（小红书/朋友圈/标题/金句/文章）：**
```
content-repurposing 确定怎么裂、给骨架与素材
  ↓
content-and-copy 完成具体文案
  ↓
brand-voice 终审 AI 味
```

**新视频衍生（从文章/观点里发现可拍的）：**
```
content-repurposing 提取适合视频的内容（观点/故事/案例/金句/时长建议）
  ↓
short-form-video-script 生成 Hook 三选一 + 时间轴口播稿 + 拍摄提示
  ↓
brand-voice 终审 AI 味
```

**纯切片（同一视频拆 30/60/90s）：** 本 Skill 直接给时长与结构建议，视频脚本细节交 `short-form-video-script`。

本 Skill 不自己写完整文案、不自己造视频结构 —— 那两件事另两个 Skill 已经有了。

## 内容矩阵

层级（登记在 `~/.workbuddy/content-assets/content-map.md`）：
```
核心主题
  └ 内容支柱
      └ 系列
          └ 单条内容（母体）
              └ 衍生内容
```

母体之间有关联就建链：哪条是支柱、哪条属于哪个系列、哪条衍生自哪条。目标是逐渐长出你自己的内容矩阵，而不是一堆互不相关的内容。

## AI 味检测（出最终稿前强制执行）

调用 `~/.workbuddy/content-system-foundation/brand-voice/SKILL.md` 检测模式，重点 8 项：
`是否像真人` / `是否像我` / `是否过度模板化` / `是否重复使用相同 Hook` /
`是否出现 AI 套话` / `是否出现营销号语言` / `是否为了平台优化牺牲真实感` /
`是否为了 SEO/流量强行塞关键词`

命中 → 自动重写，重写后复检。Voice Profile 未建时只做通用检测并标注「未经个人表达校验」。

## 失败模式

- **mass-blast**：同一段文字贴遍平台（最致命，观众立刻识别为低质）
- **AI 内容工厂感**：1 条变 20 遍、同观点换 10 种说法
- **改母体事实**：为了适配某平台把观点/数据改了
- **编造平台规则**：把不确定的算法/标签机制当事实写
- **越俎代庖**：本 Skill 自己写完整文案或造视频结构（该交给另两个 Skill）
- **凑数量**：硬裂变到质量塌掉
- **声音漂移**：衍生读起来不像我、像平台默认语气
