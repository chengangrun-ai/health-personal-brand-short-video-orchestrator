# brand-voice — 个人表达风格（Voice 层）

## 定位

短视频内容系统里的**人格/表达层**。只做一件事：

> 确保所有内容最终像我本人说出来的，而不是像 AI 写出来的。

**不负责**选题、不负责完整写稿、不负责爆款拆解、不负责分发。别的 Skill 出稿，这一层把关和改写。

**主语是「我」，不是「品牌」。** 原 Skill 的品牌 voice 机制（4 层框架、We are X not Y、配对示例库）全部保留，
只是把 subject 从 brand 换成 person，并增加「从真实素材学习」和「AI 味检测」两条主链路。

---

## 铁律（不可降级）

1. **不许凭空定义人设。** 没有真实素材支撑的特征，一律写进 `O. 待确认`，不写进正文。
   「年轻、专业、有亲和力」这类形容词禁止出厂。
2. **每一条特征必须带证据。** 格式：`依据: corpus/xxx.md #3`（素材文件 + 第几条/行）。
   找不到出处 → 不写。置信度按出现次数定：≥3 次独立素材 = 高，2 次 = 中，1 次 = 低（低置信度只进 O 段）。
3. **AI 味检测发现问题必须重写，不能只报告。** 不允许输出「这可能有 AI 味，你看要不要改」然后收工。
   检测不通过 = 直接改到通过，再交付，并附上改了什么、为什么。

## 六种调用模式

不指定时按输入内容猜：给了素材文件 → 学习；给了「这是我的修改」 → 反馈；给了稿件 → 先检测再改写。

### 1. `学习` — 从真实素材提炼表达规律

输入类型：视频 / 视频转录 / 语音转文字 / 历史文案 / 微信聊天记录 / 「我觉得像我的」别人的文案 / 「我觉得不像我的」AI 文案。

流程：
1. 原文原样存进 `corpus/`，命名 `<来源>-<日期>.md`（如 `口播-2026-09-04.md`、`微信聊天-2026-09-04.md`）。**不做润色、不纠错。**
2. 逐条抽取可观察特征，只记录**可验证的形式特征**，不评价内容好坏：
   常用词 / 常用句式 / 句子长短（估算平均字数与最长最短）/ 说话节奏（短句连发还是长句铺陈）/
   口语习惯（语气词、口头禅、断句）/ 观点怎么抛出（先结论还是先故事）/
   情绪怎么表达（直接说还是用细节带）/ 开场习惯 / 结尾习惯 / 金句习惯 /
   喜欢什么表达 / 讨厌什么表达。
3. 每条标 `依据` + `置信度`。
4. 更新 `voice-profile.md` 对应段落；置信度低的进 `O. 待确认`。
5. 报告：新增了哪些特征、哪些从 O 段升到正文、还缺什么素材。

### 2. `案例` — 像我 / 不像我 判断

给我一段文字（或指名 corpus 里某段），输出：

- 判定：**像我** / **不像我** / **介于之间**
- 像我：具体哪些表达特征命中了（指回档案条目，不写「很自然」这种空话）
- 不像我：具体哪几个词、哪个句式、哪个节奏不对；对照档案 K/L 段
- 提取：本案例新增的可复用特征（带依据）
- 归档：追加进 `M. 像我/不像我的案例库`

### 3. `改写` — 把稿件改成我的口吻

1. 先跑「检测」（第 5 节），拿到问题清单。
2. 逐处改写。**优先套用 corpus 里我真实说过的句式**，不是套用「口语化技巧」。
3. 输出**改动对照表**：`原文 → 改后 → 依据（档案条目或 corpus 出处）`。
4. 改完再自检一遍，仍命中禁用清单就继续改。
5. 改不动的地方（比如原稿信息结构本身就不像我会讲的方式）→ 明说需要重构，并给重构方案，不要硬糊一句口语词上去。

### 4. `检测` — AI 味检测

对短视频口播稿 / 口播逐字稿 / 朋友圈 / 社媒文案 / 任何要发出去的文字，逐项过一遍
[`references/ai-slop-checklist.md`](references/ai-slop-checklist.md) 的 9 个维度 + 模板句黑名单 + 越界词检查。

输出：命中项 + 证据 + 判定（通过 / 重写）。**判定为重写就直接重写**，不询问。

### 5. `反馈` — 从我的修改中学习

输入：AI 版本 + 我的修改版（或直接给我 diff）。

分析并落档：
- 我**删掉了**什么 → 大概率进 `K. 禁用表达` 或 `L. AI味高危表达`
- 我**增加了**什么 → 提炼成 `C. 句式` / `E. 口头禅` / 具体表达习惯
- 我**改变了**什么 → 语序、长短、虚实词、情绪强度，逐条记
- 我**为什么这样改** → 推断并标注为「推断」，不伪装成事实
- 反映了什么表达习惯 → 写入正文或 O 段

追加一条记录到 `feedback-log.md`（日期 + AI版/我的版 + 分析 + 落档位置）。
**同一类修改出现 3 次以上 → 从 O 段升级为 `N. 已确认的表达规则`。**

### 6. `档案` — 输出 / 更新 / 体检

- 无参数：打印当前 `voice-profile.md` 全文。
- `档案 体检`：检查哪些段落还是空的、哪些特征置信度不足、缺什么素材能补齐，输出补料清单。

## 原始框架（保留，用于把零散特征组织成系统）

原 Skill 的 4 层结构继续用，只是证据来源换成真实素材：

| 层 | 内容 | 对应档案段落 |
|---|---|---|
| L1 Voice attributes | 3–5 个「我是 X，不是 Y」的恒定特征 | A / B |
| L2 Tone shifts | 口播 / 朋友圈 / 评论回复 / 争议回应 等场景的语气位移 | B / F / J |
| L3 Vocabulary & grammar | 用词、句长、标点、人称、语气词 | C / D / E |
| L4 Examples | 配对示例库（off-voice → on-voice） | M 案例库 |

`We are X, not Y` 改成 `我是 X，不是 Y`。「不是 Y」那一半必须有 corpus 反例支撑，否则不写。

参考文件（原样保留）：
- [`references/voice-frameworks.md`](references/voice-frameworks.md) — 4 维度滑块、12 原型、We are X not Y、压力测试
- [`references/voice-document-template.md`](references/voice-document-template.md) — 完整 voice 文档模板（需要出正式文档时用）
- [`references/ai-slop-checklist.md`](references/ai-slop-checklist.md) — AI 味检测清单 + 模板句黑名单

## 冷启动：需要哪些素材

**最低可开工**（低于这个 → 不写档案，只输出缺料清单）：
- 3 份真实口语素材（视频转录 / 语音转文字 / 长语音聊天），单份 ≥300 字
- 2 条我自己写过的文案
- 1 组「我认为像我 / 我认为不像我」的对照

**可用**（能支撑稳定改写）：
- 5–10 份视频转录
- 20 条短文本（朋友圈 / 微信聊天 / 评论区回复）
- 10 组「AI 版 → 我的修改版」对照

素材怎么给都行：直接贴文本、给文件路径、给 transcripts 目录。批量投放优于一份一份喂。

1. 读 `~/.workbuddy/voice-profile/voice-profile.md` 的 **K（禁用表达）、L（AI味高危）、N（已确认规则）** 三段。
2. 出最终稿前跑一遍 `检测`，不通过就重写。

档案不存在或为空时，其他 Skill 应提示「Voice Profile 未建立」，而不是自行编造风格。

## 失败模式

- **形容词人设**：「年轻、专业、有亲和力」——等于没说，禁止。
- **无证据特征**：凭印象写的习惯，一律降级到 O 段。
- **只检测不改写**：违反铁律 3。
- **删词式去 AI 味**：把模板句删掉但没换成我的真实句式，结果变成平铺直叙的流水账。改写的目标是**换成我会说的**，不是删成中性。
- **一次素材定终身**：单条素材得出的规律一律标低置信度，等复现。
- **档案不更新**：每次反馈/新案例后必须回写 `voice-profile.md`，否则这个 Skill 只是个摆设。
